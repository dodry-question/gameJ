# gameJ — каркас под Siberian Game Jam (ноябрь 2026)

Пустой веб-каркас: Vite + TypeScript + three. **Игры пока нет, тема и концепт
не выбраны.** Всё игровое и весь интерфейс пишутся с нуля после ТЗ.

Полный контекст, запреты и план — в [`CONTEXT.md`](./CONTEXT.md).
Короткая инструкция для ИИ-агента — в [`AGENTS.md`](./AGENTS.md).

## Статус

- [ ] Тема/концепт игры — **не выбраны**
- [x] Стек выбран: веб, Vite + TypeScript + three (3D)
- [x] Каркас очищен от старого меню, настроек, тем и заглушки на Phaser
- [ ] Реализация игры — после ТЗ

## Запуск

```bash
npm install     # один раз
npm run dev     # дев-сервер с HMR
npm run build   # сборка в dist/
npm run preview # посмотреть собранный билд
```

Если `localhost:5173` не открывается (Windows + IPv6):
`npm run dev -- --host 127.0.0.1`

## Что в проекте

```
index.html        — пустой #app + подключение src/main.ts
src/main.ts       — точка входа (пока только стили и заголовок)
src/config.ts     — название/версия игры
src/style.css     — только сброс стилей, никакого UI
public/favicon.svg
docs/             — нетехнические заметки по джему (частично устарели)
CONTEXT.md        — контекст проекта и правила работы
```

## Чего здесь намеренно нет

Меню, кнопок, экранов настроек, тем оформления, аудио-движка, игровых сцен.
Это удалено, чтобы не тащить чужую вёрстку и стиль в новую игру.

## Деплой на itch.io

1. `npm run build`
2. Заархивировать **содержимое** `dist/` в zip (`index.html` в корне архива)
3. itch.io → проект → Uploads → HTML5 → загрузить zip → «This file will be
   played in the browser»

Страницу на itch лучше создать в первый же день и залить заглушку.
