# gameJ — прототип под Siberian Game Jam (ноябрь 2026)

Веб на Vite + TypeScript + three. **Готовы части 1–2:** тёмная 3D-комната,
ЭЛТ-монитор, а на его экране — рабочий стол в стиле Windows 2000 с работающим
браузером, почтой и блокнотом. Камера и карта блока C живут в терминале
`tds.exe`, который ставится из письма; при скачивании на весь экран лезет
вирус-тыква. В Netscape камер больше нет. Головоломки и fail state пока нет.

Полное ТЗ, контекст и план по частям — в [`CONTEXT.md`](./CONTEXT.md).
Короткая инструкция для ИИ-агента — в [`AGENTS.md`](./AGENTS.md).

## Запуск

```bash
npm install     # один раз
npm run dev     # дев-сервер с HMR
npm run build   # сборка в dist/
npm run preview # посмотреть собранный билд
```

Если `localhost:5173` не открывается (Windows + IPv6):
`npm run dev -- --host 127.0.0.1`

## Управление

Только мышь — как и требует ТЗ.

- навести на экран монитора → работает системный курсор (его чувствительность
  и размер не меняются); вручную рисуются только песочные часы загрузки;
- один клик по иконке на столе или в «Пуске» → открыть приложение;
- заголовок окна — перетаскивание, кнопки справа — свернуть / развернуть / закрыть;
- панель задач — свернуть/развернуть окно, часы идут по системному времени;
- в TDS камеру выбирают удержанием узла на карте: две секунды → подключение →
  постепенная загрузка кадра.

## Отладка

- `npm run dev` → `http://127.0.0.1:5173/?ui` — рабочий стол без 3D, 1:1 пиксели.
- `?ui&cam` — сразу открыть TDS на живом кадре камеры (для инструментов).
- `?ui&cam&girl` — то же плюс девушку сразу отвязывают (проверка сброса замка).
- `?ui&door` — замок считается снятым сразу, дверь открыта.
- `node tools/shot.mjs` — открывает игру в установленном Edge, кликает по иконкам,
  таскает окна и кладёт скриншоты в `%TEMP%\opencode`. Нужен запущенный dev-сервер
  на `127.0.0.1:5174` (или передай свой URL первым аргументом).
- `node tools/check-tds.mjs` — сквозная проверка: письмо → вирус-тыква →
  установка → карта → удержание камеры → проявление кадра.
- `node tools/check-lock.mjs` — сквозная проверка сброса замка: «Открыть
  дверь» → блокнот с адресом → файлы в «Мой компьютер» → Netscape →
  lockreset.local → мини-игра (удары, перезарядка волной) → дверь отперта.

## Чего здесь намеренно нет

- Механики наводки камеры на объект — следующая часть. Комната, камера КАМ-04,
  девушка и головоломка замка уже есть; смотреть камеру можно только через TDS.
- Камеры в браузере нет намеренно: единственная точка доступа — `tds.exe`,
  который ставится из письма. В Netscape — справка, интернет и мини-игры
  на отдельных доменах (пока одна: панель сброса замка).
- Готовых UI-фреймворков: весь рабочий стол рисуется вручную в canvas 2D.
- Готовых моделей и скинов: комната собрана из примитивов, текстуры генерируются
  на canvas. Из файлов — модель девушки, эмбиент, dial-up модем и записи
  дыхания и скрипа (Freesound / Wikimedia Commons, см. `CONTEXT.md`).

## Правило для ИИ-агентов: коммить и пушить постоянно

**Это обязательное правило для всех, кто работает с проектом — и для людей, и для
любых ИИ-агентов.**

Смысл не в «частоте ради галочки», а в **свежести проекта**: у любого разработчика
в любой момент должен быть доступ к актуальному рабочему коду в `origin/master`,
а не к чьей-то недоделанной локальной копии.

- Коммит после каждого логического шага: файл готов, фича работает, баг закрыт,
  документация обновлена.
- Сразу после коммита — `git push origin master`. Локальные коммиты не держим.
- Перед пушем: `npm run typecheck`, а если менялась сборка — `npm run build`.
  Битое состояние в общую ветку не пушим.
- Сообщения коммитов по-русски, в императиве: `добавь сетку фидов`,
  `почини ресайз вьюпорта`, `обнови CONTEXT.md`.
- Не делать `--force`, не переписывать чужую историю, не коммитить `node_modules`,
  `dist`, `.env` и секреты.
- В начале работы — `git pull --rebase`, чтобы не разъезжаться с остальными.

## Деплой на itch.io

1. `npm run build`
2. Заархивировать **содержимое** `dist/` в zip (`index.html` в корне архива)
3. itch.io → проект → Uploads → HTML5 → загрузить zip → «This file will be
   played in the browser»

Страницу на itch лучше создать в первый же день и залить заглушку.
