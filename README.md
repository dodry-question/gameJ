# gameJ

Прототип для геймджема: меню + настройки + стартовая игра на Phaser 3.
Дизайн плоский, переходы снаппи, игра занимает всю вкладку браузера.

## Запуск

```bash
npm install     # один раз — поставить зависимости
npm run dev     # дев-сервер с горячей перезагрузкой (HMR)
npm run build   # продакшн-сборка в dist/
npm run preview # посмотреть собранный билд локально
```

> Если `localhost:5173` не открывается (Windows + IPv6): `npm run dev -- --host 127.0.0.1`

## Структура

```
index.html              — «каркас» страницы: фон + контейнер для экранов
src/
  main.ts               — точка входа: применить настройки → показать меню
  config.ts             — НАЗВАНИЕ ИГРЫ, теглайн, версия (менять здесь)
  style.css             — компоненты интерфейса (кнопки, панели, строки).
                         Цветов здесь НЕТ — только форма.
  theme/
    themes.css          — ВЕСЬ ВИЗУАЛЬНЫЙ СТИЛЬ: 4 скина (цвета, шрифты, радиусы)
    theme.ts            — список скинов + повесить скин на <html>
  settings/settings.ts  — настройки (тема, громкости, анимации, FPS) + сохранение
  audio/audio.ts        — звук на WebAudio без единого аудиофайла
  ui/
    screens.ts          — роутер экранов (меню ⇄ настройки ⇄ игра)
    menu.ts             — главное меню
    settingsScreen.ts   — экран настроек
    about.ts            — экран «Об игре»
    fps.ts              — счётчик FPS (вкл/выкл в настройках)
  game/
    types.ts            — контракт «меню ↔ игра» (GameContext, GameHandle)
    index.ts            — ИГРОВОЙ СЛОТ: монтирует Phaser.Game на всю вкладку
    scenes/
      index.ts          — РЕЕСТР СЦЕН: добавил строку = сцена подключена
      types.ts          — что сцена получает от обёртки (цвета скина + колбэки)
      DodgeScene.ts     — заглушка «уклоняйся» (квадрат против падающих кубиков)
docs/                   — нетехнические доки (движок, джем, задачи)
```

## Управление (заглушка)

`WASD`/`стрелки` — движение, `Пробел`/клик — старт и рестарт, `P` — пауза,
`Esc` — назад в меню. Счёт: +1 очко за секунду выживания.

## Как добавить свою игру (сцену Phaser)

Текущая заглушка — `DodgeScene.ts`. Чтобы её выкинуть: удали файл и убери
строку из реестра — обёртка, меню и настройки от неё не зависят.

1. Создай `src/game/scenes/MyScene.ts`:
   ```ts
   import Phaser from 'phaser'
   import type { GameSceneApi, JamData } from './types'

   export class MyScene extends Phaser.Scene implements GameSceneApi {
     constructor() { super({ key: 'MyScene' }) }
     create() {
       // цвета скина: this.registry.get('jam').colors
       // события наружу: this.registry.get('jam').hooks.onScore(1)
     }
     startRun(): void {}   // сброс состояния, счёт в ноль
     onPress(): void {}    // Пробел / клик
     onRelease(): void {}  // отпустили кнопку
   }
   ```
2. Добавь импорт и строку в `SCENES` в `src/game/scenes/index.ts`, поменяй
   `MAIN_SCENE_KEY`.
3. Готово: меню, настройки, скины, FPS-счётчик и звук продолжают работать.

Обёртка (`src/game/index.ts`) даёт сцене: холст на всю вкладку, плавающий HUD
со счётом, оверлеи (старт/пауза/проигрыш), Esc→меню и цвета текущего скина.

## Как сделать свой скин (визуальный стиль)

1. Открой `src/theme/themes.css`, скопируй любой блок `[data-theme="..."]`.
2. Переименуй id (например, `cyber`) и поменяй цвета/шрифты/радиусы.
3. Добавь строку в `SKINS` в `src/theme/theme.ts`.
4. Скин появится в «Настройках» с превью. Переключение — мгновенное.

Минимальный набор переменных скина перечислен в шапке `themes.css`. Те же
`--color-*` читает и игра через JS — она перекрашивается вместе с интерфейсом.

## Как добавить настройку

1. Поле в интерфейс `Settings` и в `DEFAULT_SETTINGS` (`src/settings/settings.ts`).
2. Строка с объяснением «что это делает» в `src/ui/settingsScreen.ts`.
3. Прочитать значение там, где нужно: `getSettings().моеПоле`, подписаться на
   изменения — `onSettingsChange(fn)`.
