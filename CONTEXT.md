## 0. СТАТУС: ТЗ получено 29.10.2026, идём по частям

**Концепт (по ТЗ пользователя):** оператор сидит за монитором в тёмной комнате,
видит комплекс только через камеры и управляет героиней непрямо — мышью.
Интерфейс — рабочий стол Windows 2000. Стиль — низкополигональный PS1,
мрачно и грязно. Управление строго мышью.

Работаем **частями**, каждая часть = рабочий прототип + скриншот:

1. ✅ **Рабочий стол в 3D** — комната, ЭЛТ-монитор, окна, браузер, почта, звук.
2. ✅ **Комната комплекса и героиня на камерах** — карта и камера живут только
   в терминале `tds.exe`. Он ставится из письма: при скачивании вложения на весь
   экран появляется вирус-тыква, медленно тает, затем идёт установка и на столе
   появляется ярлык. TDS открывается развёрнутым на плане блока C; вход в камеру —
   удержание узла две секунды, затем подключение и постепенное проявление кадра.
   Девушка привязана к стулу, вырывается, бродит, стучит в дверь.
3. ✅ **Кухня в комнате 5** (ТЗ пользователя от 30.10): клик по объекту в кадре
   → меню команд героине, страх от свежей крови, перехват потока на отдельном
   домене, код выхода. Полная спецификация — раздел 5, подраздел «Кухня».
4. ✅ **Головоломка: сброс замка двери.** Кнопка «Открыть дверь» отдаёт адрес
   панели сброса через блокнот и файл `дверь.txt` в «Мой компьютер»; сама
   мини-игра живёт на домене `http://lockreset.local/` в Netscape (сетка узлов,
   импульсы, ОЗУ, перезарядка волной). Победа отпирает дверь, провал
   перезапускает замок. Правила — раздел 5, проверка — `tools/check-lock.mjs`.
5. ⬜ Полировка, билд, страница itch.

Правила прежние: не тащить готовые меню и скины, UI пишется с нуля, после каждой
части — скриншот и коммит с пушем.

⚠️ **Конфликт с прежним veto:** ТЗ содержит похищение, маньяка и жестокую смерть
героини, а `AGENTS.md` (п. 2) запрещает FNAF-механику и хоррор на камерах.
Часть 1 нейтральна, но перед частью 2 это надо решить с пользователем: камеры —
инструмент, а не источник страха; смерть можно подать без скримеров и без
покадрового насилия. Отдельно висит элемент джема — **тыква** (её в ТЗ нет).

## 2. Жёсткие запреты (veto пользователя)

### Никакого FNAF. Ни в каком виде.

Запрещено целиком:

- ночная смена охранника, который смотрит в камеры;
- аниматроники, монстры, существа, которые шевелятся в кадре;
- «оно приближается», скримеры, погони, паранойя-хоррор;
- любая подача «камеры = источник страха».

Камеры — **инструмент механики** (обзор, информация, тайминг, слежка как
головоломка), а не генератор ужаса. Тыква — **абсурд и комедия**, не маньяк.

### Остальное

- Не Unity / Unreal / Godot (см. раздел 3).
- Не React / R3F / Vue / Svelte и любые UI-фреймворки.
- Не тащить готовые меню, кнопки, темы, скины, стили из прежних версий проекта.
  Интерфейс пишется с нуля под конкретную игру — это осознанное требование.
- Не тянуть ассеты без CC0 или явной лицензии.
- Не использовать Phaser (был в старой версии проекта, удалён).

## 3. Стек (решено)

| Слой | Выбор |
|---|---|
| Сборка | Vite 8 |
| Язык | TypeScript 6 |
| 3D | `three` |
| Отладка параметров | `lil-gui`, только в dev |
| Пост-эффекты | `three/examples` ShaderPass или `@pmndrs/postprocessing` (по необходимости) |
| Физика | по умолчанию **не нужна**; при реальной необходимости — `@dimforge/rapier3d-compat` |
| Звук | голый WebAudio; при нужде — `jsfxr` для генерации |
| UI | HTML/CSS поверх canvas |

**Почему веб, а не Unity/Godot:** ИИ-агент не может кликать в редакторе. В вебе
цикл «правка → dev-сервер → скриншот через Playwright → правка» занимает
секунды. В Unity каждый шаг требует человека. Билд веба ~600 КБ и грузится
мгновенно на itch.

**Почему 3D дёшево:** мир собирается из примитивов (боксы, цилиндры,
плоскости), без моделей и анимаций. «Настоящий» вид даёт пост-обработка:
ч/б или зелёный тон, scanlines, шум, виньетка, таймкод, подпись `CAM 03`.
Готовые CC0-модели при необходимости: Kenney, Quaternius, Poly Pizza.

## 4. Правила кода

- **Вся игровая логика — в `src/state.ts`.** Один файл. На джеме связанность
  дешевле архитектуры.
- 3D-сцена — `src/scene.ts`, камеры и сетка фидов — `src/feed.ts`,
  пост-эффекты — `src/postfx.ts`.
- **UI — HTML/CSS поверх canvas**, не в 3D. Кнопки и панели в three.js — потеря
  времени.
- Один `WebGLRenderer`. Сетка камер — через `setViewport` + `setScissorTest`,
  не через несколько canvas.
- Параметры (углы камер, свет, сила шума) сначала крутятся ползунками `lil-gui`,
  потом финальные числа хардкодятся.
- Никаких «на будущее» абстракций, менеджеров, ECS, DI-контейнеров.
- Комментарии по-русски, коротко, по делу.
- Файл длиннее ~400 строк — повод дробить.
- Проверять результат скриншотом, а не «на глаз по коду».
- **Коммит + `git push origin master` после каждого логического шага.** Цель —
  свежесть проекта для всех разработчиков: актуальный код всегда в origin,
  а не в чьей-то локальной копии. Подробнее — `README.md` и `AGENTS.md`.

Ключевые решения части 1:

- **Стол — это текстура 960×720 на изогнутой плоскости монитора.** Не HTML-оверлей:
  так работают блики, scanlines, виньетка и «экран даёт свет в комнату».
- Клик по экрану: рейкаст по мешу → `uv` → координаты canvas. Поэтому работает
  и перетаскивание окна за пределы экрана (проекция по плоскости).
- Интерфейс рисуется вручную на canvas 2D: фаски, кнопки, панель задач, иконки.
  Никаких картинок и CSS — всё код.
- Один `WebGLRenderer` + `EffectComposer` (RenderPass → свой ShaderPass → OutputPass).
- Всё процедурное: бетон, обои, линолеум, окно, свечение — canvas-текстуры.
  Системные звуки — синтез; эмбиент комнаты и dial-up модем — Ogg-файлы.

Ассеты звука (лежат в `public/sounds/`, грузятся после первого клика):

- `ambient.ogg` — основной зацикленный эмбиент комнаты, запись звуковика команды.
- `modem.ogg` — оригинальный dial-up хендшейк, Wikimedia Commons
  («Dial up modem noises.ogg», public domain, William Termini). Играет редко
  и тихо, как фон за стеной.
- `breath.mp3` — испуганное дыхание женщины, Freesound, Aquillx «Scared
  Breathing» (CC BY 4.0). Лупится, пока открыто окно камеры; стресс управляет
  громкостью и темпом.
- `voice/hum.wav` — женщина тихо напевает под нос, Wikimedia Commons
  «Woman humming a nondescript tune.wav», PSsoundproject (Freesound 183565,
  CC0); 20.1 с, пересчитано в 22050 Гц моно.
- `voice/cry.ogg` — тихий плач со всхлипами, Wikimedia Commons
  «Cry of woman.ogg», AlucardsBride (CC0).
- `breath-man.mp3` — нервное мужское дыхание для кино провала (приближается
  из темноты после «выключения» ПК), Freesound, casiba842 «Scared Male Heavy
  Breathing» (CC0, сам автор искал такой звук и записал его сам).
- `shutdown.wav` — настоящий звук выключения Windows XP: по прямому ТЗ
  пользователя синтез не подошёл. Запись из сборника «Windows XP sounds» на
  archive.org; сам звук — собственность Microsoft, решение осознанное.

Дыхание и голос с камеры — не «звуки в комнате игрока»: они идут через
отдельную **шину камеры**. Это узкая полоса (highpass 170 Гц, lowpass 2.4 кГц,
как маленький динамик монитора), короткое эхо бетонного коридора и общий уровень
`CAM_LEVEL = 0.09` — на порядок тише компьютера (master 1.0). Шина открывается
только пока в TDS виден прямой эфир КАМ-04 и гаснет при возврате на карту;
тогда же очищаются таймеры. Пока эфир открыт, шина даёт тихий гул подвала
(два слоя шума вразнобой + далёкая труба 58 Гц), редкие капли воды в лужу
(«плинк» с падением тона и брызгами) раз в 2.4–7.2 с, иногда двойные, и
обрывок голоса девушки раз в 24–54 с (напев, а при сильном стрессе — всхлипы).
Голос грузится только при первом открытии камеры, не раньше; проверка —
`node tools/check-camera-audio.mjs`.

Шаги за спиной оператора — синтез, без файла: шорох подошвы (шум через
lowpass) плюс глухой удар пятки (низкий синус). Раз в 30–85 с за спиной
проходит серия из 3–8 тихих шагов, каждый — через свой HRTF-паннер; шаги
смещаются с одного бока на другой, поэтому звук «ходит» вокруг головы.
Громкость маленькая: не раздражает, но заставляет оборачиваться.

Общая громкость: `master` по умолчанию 1.0 (100 %), за ним лимитер
(`DynamicsCompressor`), чтобы пики не хрипели. Громкость меняется динамиком
слева от часов в панели задач (ползунок вверх-вниз) и запоминается
в `localStorage` (`sound.volume`).

### Сброс замка двери (часть 4)

Кнопка «Открыть дверь» в эфире больше не отпирает замок сама. Первое нажатие
выдаёт адрес панели сброса: открывается блокнот с `дверь.txt`, тот же файл
появляется в «Загрузках» и «Документах» «Мой компьютера» (проводник больше
не пустой: там лежат `tds.exe` после установки и пасхалка в «Изображениях»).
Повторные нажатия просто открывают блокнот снова. Адрес один —
`http://lockreset.local/`; суть схемы: камера и карта живут в TDS, а все
мини-игры — через домены в браузере.

Страница в Netscape — тёмная «панель сброса блокировки» с мини-игрой
(`src/desktop/apps/lock-game.ts`, компонент ничего не знает о браузере и
двери, наружу только `onWin`). Правила:

- схема 5×5, в центре сервер; 3–5 заражённых узлов шлют по линиям красные
  импульсы к серверу (первая посылка через ~2,6–4,7 с, дальше ~6,5 с минус
  паника: чем меньше узлов осталось, тем чаще); ребро импульс проходит
  за 1,4 с;
- курсор ходит по узлам (WASD/стрелки, шаг 115 мс), ПРОБЕЛ на красном узле
  бьёт: 15 ОЗУ за удар, узел живёт три удара, полный бой одного узла — 45 ОЗУ;
- стойка на узле глушит его сигналы (узел молчит, пока игрок на нём);
- импульс, дошедший до сервера без игрока, снимает 25 % целостности;
  на нуле контур пробит — замок перезапускается с новой раскладкой;
- у сервера ОЗУ заряжается само (9/с), а ПРОБЕЛ в такт расходящейся волне
  (когда круг касается кольца узла, окно ~±0,25 с) даёт полный заряд сразу;
  промах коротит панель на две секунды — искры, курсор беспомощен;
- сессия рассчитана на 40–60 секунд, урон стартует с запасом на две ошибки.

Победа уходит в рабочий стол: он отпирает дверь (`CameraFeed.unlock`),
девушка выбегает в коридор. Если терминал переоткрыт уже после победы,
кадр сразу показывает «ДВЕРЬ ОТКРЫТА» и не возвращает девушку к стулу.
Звуки панели — синтез: шаг реле, удар, сонар импульса, поглощение, пробой,
перезарядка, короткое замыкание и перезвон победы (раздел звуков `audio.ts`).

Пасхалки: в папке «Изображения» лежат `dodry.jpg`, `avizero.jpg` и
`Иларион.jpg` — открываются в окне просмотра
(`src/desktop/apps/image-viewer.ts`, значок `image` в `icons.ts`). В папке
«Музыка» — `песенка для малыша.ogg`: клик мгновенно открывает проигрыватель
(`src/desktop/apps/music-player.ts`, окно без задержки запуска), файл
докачивается с индикатором «загрузка аудио…» прямо в плеере, затем заводится
сам; кнопка пауза/продолжить, полоса позиции и живой эквалайзер. Играет
один раз, без зацикливания. В папке — значок ноты (`music` в `icons.ts`).

### Кухня в комнате 5 (часть 3, ТЗ пользователя от 30.10.2026)

Следующая комната за дверью комнаты 4 — импровизированная кухня. Спецификация
записана с голоса пользователя, до реализации детали помечены «уточнить».

**Сцена.** Стол, на нём окровавленный нож. Холодильник и разогревательная
плита. Освещение — висящая лампа на проводе: качается и моргает раз в 20–30
секунд; часть комнаты темнее (тёмный угол с принтером). Комната видна через
новый узел камеры 05 на карте (план уже рисовал «КОМНАТУ 5»).

**Реализовано (сцена и переход).** Геометрия кухни — `src/cctv-kitchen.ts`,
живёт в общей сцене за коридором (z −9.2…−12.8). Состояния девушки:
`run → toKitchen → kitchen` — уйдя в темноту коридора (z < −6.9), она
сворачивает в проём и появляется в кадре КАМ-05; узел 05 на карте оживает
(`Cctv.kitchenReady`), удержание подключает канал 05, камера переключается
(`Cctv.setView`, подписи шапки меняются на «КАМ 05 · КУХНЯ, БЛОК C»). На
кухне она бродит сама, обходя мебель (`KITCHEN_OBSTACLES`), и изредка
«живёт»: оглядывается, машет текущей камере.

**Реализовано (интерактив).** TAB на эфире КАМ-05 включает скан: рамки-уголки
и подписи вокруг интерактивных объектов (проецируются из мира —
`Cctv.project`), подсказка про TAB висит на кадре всегда. Клик по объекту
открывает меню команд — она идёт к объекту (прерывая свои жесты), выполняет
действие с процедурной позой и говорит субтитрами внизу кадра. Цепочка: нож →
«кровь ещё свежая», страх 0.65, нож исчезает со стола; холодильник (открытый
корпус, дверца на петле) → появляется мясо; мясо → «разрежь ножом» (без ножа
откажется) → железка с адресом `pairs.local` → диктует; принтер → читает
наклейку `print.local` (узел печати); плита — флейвор «плита ещё тёплая».
Первое поручение в тёмный угол (принтер, дверь) со страхом > 0.5 она
отклоняет — «там так темно»; повторное — идёт («…только быстро»). Каждая
важная реплика открывает блокнот «заметки.txt» и дописывает строку с временем
(адреса туда попадают сами). Кухня — заброшка: мусор и щебень, тёмные пятна
на полу, выбитая плитка, обрушенный стул, оборванный провод, щиток, приглушённый
свет. Провал перехвата: `мурзик.ogg`, маньяк (FBX-модель `Character_Killer`
из пака Characters_psx, `public/cctv/maniac.*`) неспеша идёт из проёма к ней
— дальше кино провала целиком на рабочем столе (см. блок «Кино провала» в
разделе про pairs.local). Звуки двери — через очередь событий `Cctv.events`
в ленту. Проверка — `node tools/check-kitchen.mjs` (полный цикл: от ножа до
обоих экранов).

**Узлы и гейты.** Игровые домены отвечают только «по сюжету», иначе ранний
проход ломает сценарий (софт-лок): `lockreset.local` открывается после прочтения
письма (`cameraAccess`), `pairs.local` и `print.local` — когда девушка дошла
до кухни (`Cctv.kitchenReady`); раньше — страница «403 · ДОСТУП ЗАПРЕЩЁН».
Сайт пар раздвоен: `pairs.local` — только перехват потока (победа показывает
код), `print.local`
— только печать: объяснение, строка пароля, «Печать». Наклейка на принтере в
кухне ведёт на `print.local`, железка в мясе — на `pairs.local`. Тыква-вирус
появляется не сразу после «Скачать», а после честного скачивания файла
(диалог «Загрузка файла» с прогрессом, ~3 с), дальше — как раньше.

**Страх.** Девушка в первую очередь подходит к ножу и говорит, что кровь
выглядит свежей — не свернулась, а кровь на открытом воздухе сворачивается
быстро. После этой реплики её уровень страха повышается, и в более тёмной
части комнаты она может отказаться выполнить какое-то действие (отказ = одна
из реплик; как оператор её уговорить — уточнить).

**Управление.** Клик по объекту в кадре открывает меню команд — имитация
приказа оператора героине:

- холодильник → «Осмотри» — она осматривает холодильник;
- нож → «Возьми» — она берёт нож;
- мясо (находится в холодильнике) → она спрашивает, что делать → в меню
  выбираешь нож → она режет мясо.

**Цепочка.** Осмотреть холодильник → находит кусок мяса → разрезать его
ножом → внутри железка с выбитой ссылкой на сайт головоломки → она диктует
адрес игроку (субтитрами на кадре). Отдельно принтер в кухне: наведись и
прикажи прочитать — на его наклейке адрес узла печати. Игрок открывает оба
в Netscape.

**Перехват потока на `http://pairs.local/`** (`src/desktop/apps/pairs-game.ts`,
вторая страница-игра в браузере наряду с `lockreset.local`; 31.10.2026 по ТЗ
пользователя сменила головоломку-пары — домен, гейты и выдача пароля те же).
Осу-кэтч на битах в стиле игры и криптографии: по полю густо падают чипы 0 и 1
(спавн каждые 0.2–0.38 с, 18 % бит летят в полтора раза быстрее), широкий
квадрат-ловец (84×52, вдвое больше прежнего) ездит у линии ловли (A/D или
стрелки, 540 px/с). Нужно поймать случайное число бит 15–23: с каждым
пойманным битом хэш-подпись в левом нижнем углу перегенерируется; с
достижением цели она зеленеет и пульсирует, цель+2 ещё допустимо, а третье
лишнее краснеет мгновенно — окно только вверх. Ловец и кнопка паузы
зеленеют. В зелёном окне поток сходит с ума —
биты сыплются вдвое чаще, чтобы заставить переловить. Дальше — не переловить:
успеть нажать мышью большую кнопку «ПАУЗА» в правом нижнем углу и кликнуть по
зелёному хэшу — он выдаст код выхода из 4 цифр. Пауза мышью специально: рука
на WASD, биты продолжают падать, пока тянешься к кнопке. Перед началом —
короткий экскурс в 4 строки. Перелов (больше цели+2) или пауза вне зелёного
окна: игра замирает, хэш краснеет («ПОДПИСЬ ПОВРЕЖДЕНА»), на странице —
плашка «Мне очень жаль», и рабочий стол уводит в кино провала (см. ниже).
Пропущенные биты не штрафуются — уворот часть механики («не ловить ещё»).
Код печатается на отдельном узле `print.local` (класс `PrintSite`):
объяснение, строка ввода, кнопка «Печать». Сайт пароль не проверяет —
проверяет дверь: любой введённый код честно уходит на печать; после каждой
печати строка чистится, печатать можно сколько угодно раз — бумажка
тратится у двери, так что неверный код не ломает прохождение.
Проверка — `node tools/check-pairs.mjs`.

### Анимация девушки

Позы задаются не в локальных осях костей, а в осях комнаты: наклон X,
поворот Y, крен Z, с учётом уже повёрнутого родителя (quaternion-дельта).
Позы: `SIT`/`STAND` и надстройки — ходьба, стук, рывки, дрожь. Слои:
база → дыхание → шаг (фаза от пройденного пути) → шум с несоизмеримыми
частотами → тремор от страха; вторичное движение — голова запаздывает,
корпус скручивается против бёдер, крен в поворот. Оси проверяются численно
(`tools/rig-axes.mjs`), поза — крупным скриншотом (`tools/shot-zoom.mjs`,
`tools/probe-knock.mjs`).

Подъём со стула — сценарный: корень уходит вперёд из сиденья (`RISE_STEP`),
а поза смешивается из сидячей в стоячую с наклоном вперёд и упором руками,
поэтому ноги не проходят сквозь стул. Дальше корень никогда не тянется к стулу:
бродит она впереди него, а от сиденья отталкивается радиально
(`avoidChair`, радиус 0.5) — минимальная дистанция до стула за прогон 0.57.
Разворот — с ограничением скорости доворота (2.4 рад/с), и пока корпус не
довернулся, шаг мельче: нет бега боком. Руки в покое висят вдоль тела,
в посадке кисти на коленях, локти снаружи торса. Живость — случайные жесты
раз в несколько секунд: оглядывается, останавливается и машет камере, ёжится,
теребит свитер; во время жеста она стоит на месте, потом идёт дальше.
Мах — верхняя рука поднята кистью к голове, локтем вниз, и развёрнута к камере:
кисть на высоте глаз, смещена в сторону объектива, ладонь к зрителю, пальцы
дрожат. Жест снимается при выпуске (`release`), иначе она замирает на пороге.

Побег: цель — глубь коридора (−0.85, −7.2), а не проём. Если идти сразу в
(−0.85, −7.2), луч из объектива проходит через проём при x ≈ 0.4, поэтому она
остаётся в кадре, пока пятится, и скрывается в тумане на `z < −6.9`
(страховка — 9 с). Проверка — `node tools/check-girl.mjs`.

Как ещё можно делать естественные анимации (варианты на будущее, сейчас не
используются):
- **Готовые клипы Mixamo** (CC0-подобная лицензия Adobe): idle scared / walk /
  run / knock; подмешивать через AnimationMixer и добавлять процедурный слой
  страха поверх. Быстро, но нужен ретаргет и весит больше.
- **Видео-мокап**: Rokoko Vision 3.0, Plask, DeepMotion, QuickMagic, Move AI —
  снять 10-секундную игру и выгрузить FBX/BVH, затем ретаргет
  (`upf-gti/retargeting-threejs`). Дёшево по времени, но требует записи.
- **AI-генерация движения по тексту**: MotionDiffuse/MDM/MLD, NVIDIA Kimodo —
  пока сыровато для браузера и требует отдельного пайплайна.
- **Физика/IK**: foot-lock IK, spring-bone для вторичного движения, additive
  слои — дёшево в рантайме, хорошо сочетается с текущим процедурным подходом.

Решение на джем: остаёмся на процедурной анимации (нет ассетов, мгновенная
правка числами), при запасе времени — записать 2–3 клипа видео-мокапом.

Старт — чистый рабочий стол без окон. Курсор — системный, со своей
чувствительностью и размером; вручную рисуются только песочные часы на время
загрузки. Программы открываются с задержкой «чтения с диска»:
браузер 1.5 с, почта 1.1 с, остальное быстрее. Через 5 секунд после входа
появляется уведомление о новом письме; в письме — установщик `tds.exe`
с акцентом на кнопке «Скачать».

## 6. Команды и деплой

```bash
npm install
npm run dev        # HMR
npm run typecheck  # tsc --noEmit
npm run build      # dist/ — правильный билд всегда (см. ниже)
npm run preview
npm run dev -- --host 127.0.0.1   # если localhost не открывается (IPv6)
```

**Билд правильный по умолчанию.** В `vite.config.ts` стоит `base: './'` —
все пути в `dist/` относительные (`./assets/...`), поэтому собранная игра
работает на itch.io (HTML5-версия отдаётся из вложенного пути, не из корня)
и открывается с диска без сервера. В `index.html` favicon тоже относительный.
Проверка собранной версии целиком: `npm run preview`, затем
`node tools/check-pairs.mjs http://127.0.0.1:4173/?ui&cam&kitchen` — вся
цепочка перехвата на прод-бандле. Порог предупреждения о размере чанка
поднят до 950 КБ: three.js в одном бандле (~860 КБ) — осознанное решение
для джема.

Деплой на itch.io: `npm run build` → zip **содержимого** `dist/`
(`index.html` в корне архива) → Uploads → HTML5 → «played in the browser».
Страницу на itch создать в первый вечер и залить заглушку.
Опционально — `butler` для пушей из консоли.
